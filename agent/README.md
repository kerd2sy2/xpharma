# برنامج وكيل ربط ومزامنة مستودع الأدوية (XPharma Sync Agent)
### ربط منظومة ORGA SOFT ومستودع الأدوية مع منصة XPharma السحابية

---

## طريقة التشغيل (برنامج تنفيذي مستقل):

1. قم بتشغيل الملف:
   **`xpharma-agent.exe`** (انقر عليه مرتين للفتح مباشرة بدون ظهور أي شاشة سوداء).
2. ستفتح لك نافذة التحكم الرئيسية تلقائياً.
3. قم بإدخال البيانات الثلاثة التالية فقط:
   - **مسار ملف قاعدة البيانات (Firebird DB Path):** مثل `D:\ORGA_SOFT\DATA\ORGA.GDB`.
   - **عنوان IP الماستر أو السيرفر (Master IP):** مثل `127.0.0.1`.
   - **مفتاح الربط والتوكن السحابي (API Token):** المفتاح الخاص بحساب المستودع.
4. اضغط على زر: **"حفظ وبدء المزامنة"**.

---

## مميزات محرك المزامنة المستمر:
- **واجهة مستقلة نقية بدون شاشات أوامر:** يعمل مباشرة كنافذة تطبيق احترافية دون الحاجة لشاشات سوداء أو أكواد.
- **حماية كاملة لقاعدة بيانات المخزن:** يرفع البيانات على دفعات خفيفة ومدروسة (100 فاتورة بكل دفعة مع استراحة 1.5 ثانية) لمنع أي إجهاد أو بطء في أجهزة المبيعات.
- **التشغيل التلقائي مع فتح الويندوز:** يعمل البرنامج تلقائياً في الخلفية مع كل إعادة تشغيل للكمبيوتر.
- **مراقبة وتحديث مستمر:** فحص مستمر كل 60 ثانية لمزامنة أي فواتير أو سندات جديدة تلقائياً.
- **رفع البيانات التاريخية كاملة:** رفع الفواتير وسندات القبض وحسابات العملاء بالكامل.
- **دعم كامل للغتين العربية والإنجليزية.**
