# 🏢 برنامج وكيل ربط ومزامنة مستودع الأدوية (XPharma Sync Agent)
### ربط منظومة ORGA SOFT ومستودع الأدوية مع منصة XPharma السحابية

---

## 🚀 طريقة التشغيل السهلة (برنامج واحد فقط):

1. قم بتشغيل برنامج:
   **`xpharma-agent.exe`** (انقر عليه مرتين للفتح).
2. ستفتح لك نافذة البرنامج تلقائياً.
3. قم بإدخال البيانات الثلاثة التالية فقط:
   - **مسار ملف قاعدة البيانات (Firebird DB Path):** مثل `D:\ORGA_SOFT\DATA\ORGA.GDB`.
   - **عنوان IP الماستر أو السيرفر (Master IP):** مثل `127.0.0.1`.
   - **مفتاح الربط والتوكن السحابي (API Token):** الصق المفتاح الخاص بحسابك.
4. اضغط على زر: **"حفظ وبدء المزامنة الهادئة"**.

---

## 🐢 مميزات نمط المزامنة الهادئة (Gentle Sync):
- **حماية كاملة لقاعدة بيانات المخزن:** يرفع البيانات على دفعات خفيفة ومدروسة (100 فاتورة بكل دفعة مع استراحة) حتى لا يتأثر أي مستخدم يعمل على الأورجا سوفت داخل المستودع.
- **حماية سيرفر السحابة من التهنيج:** يمنع أي استهلاك مفاجئ لموارد السيرفر.
- **رفع البيانات كاملة:** يرفع جميع الفواتير التاريخية وسندات القبض وحسابات الصيدليات من البداية.
- **شاشة عربية واضحة ومباشرة:** بدون أي شاشات معقدة أو كلام مش مفهوم.
