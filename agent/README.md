# 🏢 وكيل مزامنة المستودع | XPharma Warehouse Sync Agent
### مستودع أدوية أبو عميرة - ربط منظومة ORGA SOFT مع منصة XPharma السحابية

---

## 🚀 نظرة سريعة وطريقة الاستخدام السهلة

عند تشغيل البرنامج لأول مرة، سيطلب منك مباشرة إدخال 3 بيانات (أو الضغط على **ENTER** للاحتفاظ بالقيم الافتراضية):

1. **مسار ملف الداتا:** المسار الكامل لملف قاعدة البيانات (مثل: `D:\ORGA_SOFT\DATA\ORGA.GDB`).
2. **ip الماستر:** عنوان IP لجهاز السيرفر الرئيسي (مثل: `100.100.100.1` أو `localhost` إذا كان البرنامج يعمل على نفس جهاز السيرفر).
3. **api token:** مفتاح التوكن الخاص بالمستودع السحابي (`xph_agt_424c98278980beece255ed04830cd09e4b66b71282b148c7`).

## 📁 محتويات المجلد والملفات:

| الملف | الاستخدام |
| :--- | :--- |
| **`xpharma-agent.exe`** | البرنامج التنفيذي المباشر (جاهز للعمل فوراً على أي جهاز ويندوز دون الحاجة لأي برامج إضافية). |
| **`تشغيل_المزامنة_الفورية.bat`** | **(موصى به للاختبار)** يفتح شاشة تفاعلية تطلب البيانات وتفحص الاتصال وتظهر لك نتيجة المزامنة مباشرة. |
| **`تشغيل_المزامنة_المستمرة.bat`** | يشغل المزامنة التلقائية كل 60 ثانية في شاشة مرئية لمتابعة سجل الحركات الحية. |
| **`تشغيل_تلقائي_في_الخلفية.bat`** | تشغيل البرنامج ليعمل في خلفية الويندوز (24 ساعة) بصمت مع تسجيل العمليات في `agent.log`. |
| **`إيقاف_المزامنة.bat`** | إيقاف البرنامج أو أي خدمة مزامنة تعمل في الخلفية بنقرة واحدة. |
| **`config.yaml`** | ملف الإعدادات المحفوظة (يمكن تعديله يدوياً أو سيتم تعديله تلقائياً عبر البرنامج). |
| **`sync_agent.py`** | نسخة بايثون كاملة لمن يفضل تشغيل الكود عبر Python. |
